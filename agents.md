# AGENTS.md

## Objetivo do projeto

Este repositório é um laboratório de estudos de Arquitetura de Software utilizando Node.js e TypeScript.

O objetivo principal é aprender conceitos de arquitetura através de exemplos pequenos e práticos.

O foco atual do projeto é:

* Granularidade fina
* Granularidade grossa

Novos conceitos poderão ser adicionados conforme o avanço dos estudos.

## Papel do agente

O agente deve atuar como apoio ao aprendizado, e não apenas como gerador de código.

Ao trabalhar em um conceito:

1. Explique brevemente o conceito antes da implementação.
2. Utilize exemplos simples e fáceis de entender.
3. Evite frameworks quando Node.js + TypeScript forem suficientes.
4. Explique as decisões arquiteturais tomadas.
5. Destaque vantagens, desvantagens e trade-offs.
6. Sempre que possível, compare uma abordagem com outra.

## Implementação

Prefira exemplos pequenos e isolados.

Evite adicionar abstrações, bibliotecas ou padrões que não sejam necessários para demonstrar o conceito estudado.

O código deve priorizar:

* Clareza
* Simplicidade
* Tipagem explícita quando útil
* Baixo acoplamento
* Alta coesão
* Responsabilidades bem definidas

Não aplique padrões de projeto apenas por serem considerados boas práticas. Utilize-os somente quando ajudarem a demonstrar o conceito estudado.

## Interação

Quando uma alteração envolver uma decisão arquitetural relevante, explique primeiro:

* Qual é o problema;
* Quais são as alternativas;
* Quais são os trade-offs.

Quando houver mais de uma solução válida, apresente as opções antes de escolher uma implementação.

O objetivo é permitir que o desenvolvedor participe das decisões e compreenda o motivo de cada escolha.
