# 🏗️ Software Architecture Lab

Laboratório prático de **Arquitetura de Software** utilizando **Node.js e TypeScript**.

Este repositório tem como objetivo colocar em prática conceitos estudados sobre arquitetura e design de software através de exemplos simples e comparativos.

## 📚 Granularidade

O primeiro conceito abordado é a **granularidade de componentes**, comparando duas abordagens:

* **Granularidade grossa:** componentes maiores, que concentram mais responsabilidades.
* **Granularidade fina:** componentes menores e mais especializados, com responsabilidades mais específicas.

Os exemplos demonstram como diferentes níveis de granularidade podem impactar a organização, reutilização e manutenção do código.

## 🛠️ Tecnologias

* Node.js
* TypeScript
